## 对客户端设计的影响

### 0. 重大实测发现：官方 PC 网页端当前没有登录入口（2026-10-07，6 轮验证）

| # | 验证方法 | 结果 |
| --- | --- | --- |
| 1 | 扫描 `www.baicizhan.com/` 首页全部 DOM 元素中含"登录"的文本 | 0 个匹配 |
| 2 | 扫描首页全部 `<a>` 链接（25+ 条） | 全部为营销/公司/活动/协议链接，无登录/学习入口 |
| 3 | 截图官网右上角（1280×900 视口） | 纯蓝色背景，无任何按钮 |
| 4 | 逐个访问 8 个学科页（`?learning=...`） | 均为营销展示页（词书列表），无登录入口 |
| 5 | 分析官网前端 JS（desktop.*.js, 45KB） | 无 `login`/`passport`/`signin`/`token`/`api` 任何登录相关代码 |
| 6 | 访问 `passport.baicizhan.com/` | 根路径 404；公开仅 `/privacy/*` 协议页 |

**结论**：百词斩官方网站当前是**纯营销展示页**（引导下载手机 App），
未提供 PC 网页登录/学习功能。搜索引擎中"官网右上角有登录按钮"的描述与实测不符（疑似过时信息）。

**对本项目的影响**：
- "通过官方网页登录获取会话"这条路径在当前官方产品形态下**不可行**——这是官方侧的产品形态限制；
- 应用会继续保留登录入口与完整的会话捕获/验证管线：一旦官方恢复网页登录（或开放其他公开渠道），
  现有的域名白名单、SessionProbe 验证、诚实状态机即可直接接入；
- 本地学习模式为完整可用状态，不受影响。

### 1. 登录状态无法从 HTML 直接判定

由于主站是 SPA，公开 HTML 在所有状态下几乎相同。因此：

- **HTTP 200 ≠ 已登录**（v0.2.0 已修复：0.1.0 曾用此方式误判）；
- **Cookie 数量 > 0 ≠ 已登录**（未登录也可能有匿名统计 Cookie，已修复）；
- SessionProbe 的策略：携带会话访问官方首页，检查
  1) 是否被重定向到登录入口（`passport.*` / login 路径）；
  2) 响应中是否出现登录后特征（退出登录 / 个人中心 等）；
  3) 响应中是否出现未登录特征（立即登录 / 请先登录 等）。
- 找不到可靠证据时，状态显示为 **「会话待验证」**（`unverified`），
  绝不显示为已登录。这是当前 SPA 结构下的诚实结论。

### 2. 官方数据读取（READ）现状

| 数据 | 状态 | 说明 |
| --- | --- | --- |
| 账号资料 | ❌ 暂不支持 | SPA 未提供公开可验证的静态数据入口；不猜测/不探测私有接口 |
| 当前词书 | ❌ 暂不支持 | 同上 |
| 学习计划 | ❌ 暂不支持 | 同上 |
| 今日进度 | ❌ 暂不支持 | 同上 |
| 复习列表 | ❌ 暂不支持 | 同上 |
| 单词内容/音频 | ❌ 暂不支持 | 官方未提供公开授权访问；本地词书 + 系统 TTS 替代 |

### 3. 后续研究方向（需要用户配合）

如果希望进一步接入官方数据，可以在**用户本人登录后**做以下研究（属于正常网页流程观察）：

1. 在官方登录窗口中登录后，于官方页面按 `F12` → Network 面板；
2. 观察页面**自身**加载的数据请求（域名、路径、方法、必需 Header）；
3. 将观察结果记录到本文件（**不要包含任何 Cookie/Token 具体值**）；
4. 评估其是否为"官方网站正常网页流程本身使用的数据"——只有满足该条件、
   且不依赖签名/风控绕过时，才允许在 `OfficialWebAdapter` 中实现对应 READ。

**注意**：手机 App 的私有接口（含签名算法）无论是否可复现，均不在本项目的允许范围内。

## 安全边界（0.2.0 实现，单元测试验证）

| 项目 | 状态 |
| --- | --- |
| 出站请求白名单 | 仅 `baicizhan.com` 及其子域（`is_allowed_official_host`，单元测试覆盖 evilbaicizhan.com / baicizhan.com.evil.com 等边界） |
| 跨域重定向 | 离开官方域立即停止，绝不带着认证 Cookie 继续跳转 |
| Cookie 按域管理 | 按 host / path / secure / 过期匹配发送；非官方域 Cookie 在采集阶段即被丢弃 |
| Cookie 日志 | 值与名称均不落日志、不进错误信息、不进能力报告 |
