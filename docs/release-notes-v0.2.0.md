# 百词斩桌面版 v0.2.0（非官方）

安全性、真实性、同步架构专项升级版。**非百词斩官方客户端**，仅供个人学习使用。

## 本版重点（不是加页面，而是把"真实与安全"做扎实）

### 🔒 安全修复

- **认证 Cookie 域名白名单**：携带会话的请求只允许发往 `baicizhan.com` 及其子域。
  `evilbaicizhan.com`、`baicizhan.com.evil.com`、`example.com` 等一律拒绝
  （已由 5 个 Rust 单元测试验证边界）。出站请求全面限制在官方域名。
- **Cookie 按域名管理**：保存 `name/value/domain/path/secure/expires/httpOnly` 全字段；
  发送时按 host / path / 过期精确匹配，绝不把所有 Cookie 发给所有请求。
- **跨域重定向防护**：重定向一旦离开官方域立即停止，认证 Cookie 绝不跟随跳转。
- **Cookie 隐私**：会话仅存 Windows 凭据管理器；名称与值均不落日志、不进错误信息、不进能力报告。

### ✅ 登录真实性

- **彻底移除"Cookie 数量 > 0 = 已登录"** 与 **"首页 HTTP 200 = 已登录"** 两个旧判定。
- 新增 **SessionProbe**：捕获会话后携带会话访问官方页面，检查重定向与登录特征标记。
- 新增**七态登录状态机**：未登录 / 会话待验证 / 验证中 / 已验证登录 / 已过期 / 离线（未验证）/ 身份未验证。
  官方 SPA 页面无法提供身份证据时，如实显示「会话待验证」，**绝不显示为已登录**。
- 能力检测不再默认"已登录"（移除 hardcode），只有验证通过的会话才进行官方能力检测。

### 📊 官方 / 本地状态严格分离

- 界面改为三行式真实状态：**本地数据：已保存 / 百词斩账号：当前状态 / 官方学习同步：暂不可用（或已同步）**。
- 全 UI 清除「同步完成」等无官方同步时的误导措辞。
- 「设置 → 同步」重做为三块：① 账号连接 ② 本地数据 ③ 百词斩官方能力（运行时检测）。
- 操作队列按类型分批处理（学习记录 / 收藏各自独立标记，互不污染）；
  只有官方真正写入成功才同时更新队列与 `study_records.synced`，并记录官方同步时间。

### 🔍 官方网页能力研究

- 新增 [docs/official-web-capabilities.md](https://github.com/2011126630z-commits/baicizhan-desktop/blob/main/docs/official-web-capabilities.md)：
  记录对官网正常网页流程的公开观察（SPA 架构、passport 登录域、无法从 HTML 判定登录态等）。
- 官方 READ 能力经研究当前仍不可用，如实保持「暂不支持」；不猜测、不探测私有接口。

### 本地功能全部保留

SQLite、本地词书、CSV 导入、新词学习、SRS 复习、认识/模糊/不认识、收藏、
统计、学习时长、连续天数、键盘快捷键、系统 TTS、小窗、托盘、主题、开机启动 —— 未做破坏性改动（已实测）。

## 安装

下载 `BaicizhanDesktop_Setup_x64.exe` 双击安装（用户级安装，无需管理员权限）。
如已装 0.1.0，直接覆盖安装即可，本地学习数据保留。

## 已知限制

- 官方渠道仍未开放学习数据读写，本地模式为完整可用状态（界面明确标注）。
- 官方页面未提供身份标记时显示「会话待验证」——这是 SPA 结构下的诚实结论。
- MSI 安装包需联网下载 WiX 工具链，本次未包含。
