# 百词斩桌面版 v0.2.1（非官方）

登录链路真实性专项修正版。**非百词斩官方客户端**，仅供个人学习使用。

## 本版修正

### ⚠️ 撤回并修正上一版的错误结论

上一版曾写"百词斩官方 PC 网页端没有登录入口"——**该结论错误，已撤回**。
正确结论（直接测试 `/login`、`/hello` 后得出）：

- 官方**登录页 `https://www.baicizhan.com/login` 存在且服务端在线**
  （提交测试账号返回业务错误「无效用户名或密码」，证明服务端在处理登录请求）；
- 登录窗口已改为**直接打开 `/login`**（不再是营销首页）；
- 上一版"没有登录入口"的界面文案已全部移除。

### 微信登录根因定位（做对照测试）

| 测试 | 结果 |
| --- | --- |
| 标准浏览器打开官方登录页 → 点微信 | ❌ 微信返回「redirect_uri 参数错误」 |
| Tauri 登录窗口 → 点微信 | ❌ 同样的错误 |
| 两者 OAuth URL 对比 | ✅ 完全一致（服务端 302 生成，任何 UA 下相同） |
| 是否发生二次编码 / URL 篡改 | ❌ 无（全项目搜索 + UA 对照双重确认） |

**根因**：微信开放平台登记的回调域与线上生成值（`http://baicizhan.com/auth/weixin/callback`，
裸域 + http）不符——**官方服务端配置问题**，标准浏览器同样复现，客户端无法也不应通过修改
`redirect_uri` "修复"。

**本版处理**：登录界面明确标注微信登录当前异常并**建议使用邮箱登录**；微信入口保留（官方修复后即可用）。

### 🔒 安全改进：认证导航白名单（与 Cookie 白名单严格独立）

- **AUTH_NAVIGATION_ALLOWLIST**：登录窗口仅允许导航到官方域 + 已知 OAuth 提供方
  （微信/微博/人人），其他域拦截并记录日志；
- **Cookie 白名单不变**：百词斩 Cookie 仍只发送给 `baicizhan.com` 及子域，
  第三方 OAuth 域**永远**收不到（单元测试覆盖）；
- 新增单元测试 `auth_navigation_allowlist`（6 个测试全部通过）。

### 本地功能全部保留

SQLite、本地词书、学习、SRS 复习、收藏、统计、键盘、TTS、小窗、托盘、主题等未做改动。
