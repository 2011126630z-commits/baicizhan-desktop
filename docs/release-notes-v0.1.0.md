# 百词斩桌面版 v0.1.0（非官方）

Windows 桌面背单词客户端 —— Tauri 2 + React + Rust，安装包仅 3.6 MB。
**非百词斩官方客户端**，仅供个人学习使用。

## 安装

下载下方 `BaicizhanDesktop_Setup_x64.exe` 双击安装（用户级安装，无需管理员权限），
安装后自动创建桌面与开始菜单快捷方式。

## 本版功能

- **官方登录**：内置 WebView2 打开百词斩官方网页完成登录（扫码/短信/密码均在官方页面进行，本程序不接触密码）；会话保存于 Windows 凭据管理器
- **键盘背词**：`空格`发音 · `1`认识 · `2`模糊 · `3`不认识 · `回车`继续 · `F11`沉浸模式 · `Esc`暂停 · `Ctrl+D`收藏，快捷键可自定义（含冲突检测）
- **本地学习内核**：词书、SRS 复习、收藏、统计全部存于本地 SQLite；所有学习操作先写本地队列（幂等），断网不丢记录
- **同步能力检测**：启动时探测官方渠道可用能力，官方未开放的能力在界面中如实标注「本地记录，暂未同步至百词斩」，**绝不伪造同步结果**
- **小窗背词**：400×280 无边框小窗，可置顶、拖动，边做别的事边复习
- **系统托盘**：打开主窗口 / 开始今日学习 / 小窗背词 / 退出；关闭窗口行为可记忆
- **深浅主题** + 跟随系统、三档字体大小、CSV 词书导入、离线模式

## 已知限制

- 学习进度暂不能写回手机百词斩（官方网页未开放对应渠道，界面已明确标注）
- 词书默认内置一份自制核心词汇（47 词），可在「单词书」页面导入 CSV 扩展
- MSI 安装包需联网下载 WiX 工具链，本次未包含；NSIS 安装包功能完全一致
