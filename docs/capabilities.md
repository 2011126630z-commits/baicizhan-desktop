# 百词斩桌面版 · 数据能力报告（初始）

> 本文件为项目初始版本记录。应用运行后，内置 CapabilityDetector 会在
> 「设置 → 同步 → 数据能力」展示实时报告，并可通过「导出能力报告」更新本文件。

检测原则：

- 只使用百词斩官方网页正常登录产生的会话；
- 不破解账号系统、不绕过验证码/风控/反爬、不破解私有 API 签名、不绕过证书校验；
- 某项数据无法通过安全公开渠道获得时，保留适配层接口并如实标注，**绝不伪造同步成功**。

## 数据流

1. 用户学习操作 → 写入本地操作队列（operationId 幂等）→ UI 立即更新；
2. SyncManager 后台尝试同步：
   - 官方渠道支持 → 推送并标记 `synced`；
   - 网络不可用 → 保留 `pending`，恢复网络后自动重试；
   - 官方渠道不支持 → 标记 `unsupported`，界面显示「本地记录，暂未同步至百词斩」。
3. 界面状态标记只有五种：`synced / local / pending / failed / unsupported`，
   **unsupported 永远不会显示为 synced**。
