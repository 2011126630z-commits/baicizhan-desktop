# 百词斩桌面版 · 数据能力报告（v0.2.0 初始版）

> 本文件为 0.2.0 初始记录。应用运行后，CapabilityDetector 会基于**真实登录状态**
> 重新生成报告（设置 → 同步 → 导出能力报告），并覆盖本文件。

## 账号状态（运行时检测，三态可区分）

| 状态 | 含义 |
| --- | --- |
| 未登录 | 本地无会话 |
| 会话待验证 / 身份未验证 | 已捕获官方 Cookie，但官方页面未提供可验证身份的标记（**绝不显示为已登录**） |
| 已验证登录 | 携带会话访问官方页面并发现登录特征 |
| 会话已过期 | 曾验证通过，现被官方入口重定向 / 呈现未登录状态 |
| 离线（未验证） | 网络原因无法验证（不等于失效） |

## 数据流（0.2.0）

1. 学习操作 → 本地 SQLite 操作队列（operationId 幂等）→ UI 立即更新；
2. SyncManager 分批处理队列（study_record / favorite 各自独立标记，
   互不污染）——状态仅可能是：`synced / local / pending / failed / unsupported`；
3. **只有官方渠道真正写入成功**时：队列标记 `synced` **并且**同步更新
   `study_records.synced = 1`（`mark_study_records_synced`），同时记录官方同步时间；
4. 其余情况一律如实显示本地状态，界面措辞中不会再出现"同步完成"冒充官方同步。
