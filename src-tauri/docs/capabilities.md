## 数据流说明

- 所有学习操作先写入本地 SQLite 操作队列（含 operationId，幂等），UI 立即更新，再由 SyncManager 决定同步去向。
- 状态标记：synced=官方已同步 / local=仅本地 / pending=待同步 / failed=失败可重试 / unsupported=官方渠道暂不支持。
- 界面上 unsupported 永远不会显示为 synced。
